# 06 · 插件配置详解（Plugin/config.env）

> 位置：`VCPToolBox/Plugin/<插件名>/config.env`（每个插件独立配置文件）  
> 机制：插件启动时读取自身目录的 `config.env`；未配置时回退 `config.env.example` 默认值。  
> 修改后重启：`pitchfork restart vcp-main`

## 2. Agent 通讯类

### 2.1 AgentAssistant（Agent 间通讯/定时唤醒）

**机制**：动态发现所有 `AGENT_{BASENAME}_MODEL_ID` 环境变量，每个 BASENAME 一组配置。

```bash
# 基础
AGENT_ASSISTANT_MAX_HISTORY_ROUNDS=5     # 每 Agent 对话历史轮数
AGENT_ASSISTANT_CONTEXT_TTL_HOURS=12    # 上下文有效时间（小时）
AGENT_ALL_SYSTEM_PROMPT=...             # 全局通讯大厅提示词
PLUGIN_COMMUNICATION_TIMEOUT=358000     # 通讯超时 ms

# 每个 Agent 一组（BASENAME 可用任意 ASCII 名）
AGENT_{BASENAME}_MODEL_ID="qwen3.6-plus"          # 模型（必须网关可用）
AGENT_{BASENAME}_CHINESE_NAME="张仲景"             # 调用名（AI 用此名呼叫）
AGENT_{BASENAME}_SYSTEM_PROMPT="{{张仲景}}"        # 提示词（{{名字}} 引用角色卡）
AGENT_{BASENAME}_MAX_OUTPUT_TOKENS=8000
AGENT_{BASENAME}_TEMPERATURE=0.7
AGENT_{BASENAME}_DESCRIPTION="中医张仲景，经方医宗"

# 异步委托
DELEGATION_MAX_ROUNDS=15              # 委托最大轮数（防死循环）
DELEGATION_TIMEOUT=300000             # 委托超时 ms
DELEGATION_SYSTEM_PROMPT=...          # 委托任务系统提示词
DELEGATION_HEARTBEAT_PROMPT=...       # 委托心跳提示词
```

**推荐角色阵容**（与 agent_map.json / Agent/ 角色卡联动）：

| BASENAME | 中文名 | 角色 |
|---|---|---|
| NOVA | Nova | 系统主助手 |
| AGENT | 张仲景 | 中医（经方医宗） |
| AGENT_2 | 叶天士 | 中医（温病大家） |
| AGENT_3 | 教员 | 战略规划 |
| SNOWCODER | SnowCoder | 编码天才 |
| CIO | 首席投资官 | 宏观分析/资产配置 |
| CRO | 首席风险官 | 风险审计 |
| RM | 客户关系总监 | 需求对齐 |

## 10. 配置迁移与维护

### 10.1 从 example 生成

```bash
# 单个
cp Plugin/<名字>/config.env.example Plugin/<名字>/config.env

# 批量（所有缺 config.env 的插件）
for d in Plugin/*/; do
  [ -f "$d/config.env.example" ] && [ ! -f "$d/config.env" ] && cp "$d/config.env.example" "$d/config.env"
done
```

### 10.2 模型名规范（最重要的坑）

**所有模型名必须与网关 `/v1/models` 返回的 id 完全一致**：

```bash
# 查看网关可用模型
curl -s http://localhost:6005/v1/models -H "Authorization: Bearer <Key>" | jq '.data[].id'

# 检查插件配置中的模型是否可用
curl -s http://localhost:6005/v1/models -H "Authorization: Bearer <Key>" | grep -o '"id":"[^"]*"' | grep -i minimax
```

- ❌ 错误：`google/gemini-embedding-2-preview`（带厂商前缀）、`MiniMax-M2.7-highspeed`（已下架）
- ✅ 正确：`gemini-embedding-2-preview`、`qwen3.6-plus`、`gemini-3.5-flash`、`DeepSeek-V4-Flash`、`Qwen3-Reranker-8B`

**⚠️ 向量模型白名单坑（embedding 灾备相关）**：

- 网关 `/v1/embeddings` 路由有白名单校验，白名单只从 `WhitelistEmbeddingModel` 读取
- **灾备模型（`EmbeddingModelBackup*`）不会自动进白名单**，必须显式加入 `WhitelistEmbeddingModel`（逗号分隔）
- 漏配症状：灾备请求被 400 拦截，日志报 `模型不匹配向量化模型白名单`
- 完整配置示例见 [04-配置详解.md §3 向量模型](04-配置详解.md)

## 11. 插件类型速查

| 类型 | 行为 | 示例 |
|---|---|---|
| `synchronous` | AI 调用阻塞等结果 | 搜索、计算、文件 |
| `asynchronous` | 立即返回任务 ID，后台执行 | 视频生成、深度研究 |
| `static` | 占位符注入，无调用入口 | 系统信息、时间 |
| `service` | 常驻服务 | ImageServer、VCPBridgeServer |
| `hybridservice` | 常驻 + 可调用 | DailyNote、LightMemo |
| `messagePreprocessor` | 消息预处理 | ImageProcessor |

> 完整的 300+ 插件清单可在管理面板（:6006）插件页查看与开关。
