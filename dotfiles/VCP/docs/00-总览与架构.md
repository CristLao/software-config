# VCP 从零部署 · 总览与架构

> 版本：VCPToolBox 1.1+ / VCPChat（2026-08 版）  
> 部署环境：Linux（Arch / WSL2）/ macOS，Node 22 + pitchfork + uv

---

## 1. VCP 是什么

VCP 是一套 **AGI 运行时**：部署在 AI 模型 API 与前端应用之间的中间层服务器，提供持久记忆、工具调用、Agent 自主行动、跨端统一意识等能力。

部署后你会得到三个服务：

| 服务 | 组件 | 端口 | 说明 |
|---|---|---|---|
| 主服务 | VCPToolBox `server.js` | 6005 | AI 对话 API、工具调用、记忆/知识库、WebSocket |
| 管理面板 | VCPToolBox `adminServer.js` | 6006 | Web 管理后台（插件、Agent、日记、知识库） |
| 桌面客户端 | VCPChat（Electron） | 动态 | 聊天 GUI，可选部署 |

前置依赖：一个 OpenAI 兼容的 API 网关（如 NewAPI / OpenRouter），提供聊天与向量模型。

## 2. 部署全景（按顺序）

```
┌──────────────────────────────────────────────────────────┐
│ 0. 准备上游 API 网关（NewAPI 等，提供 chat + embedding） │
├──────────────────────────────────────────────────────────┤
│ 1. 安装工具链：mise → node 22 / uv / pitchfork           │
│ 2. 获取源码：VCPToolBox + VCPChat                        │
│ 3. 配置环境：config.env + multimodal-config.json         │
│    + agent_map.json + Agent 角色卡                       │
│ 4. 安装依赖：npm（含原生模块）+ Python（uv）             │
│ 5. 构建：AdminPanel-Vue 前端 + Rust 组件                 │
│ 6. 启动：pitchfork start vcp-main vcp-admin              │
│ 7. 验证：/v1/models、管理面板、聊天                      │
└──────────────────────────────────────────────────────────┘
```

## 3. 目录结构

```
VCP/
├── mise.toml              # 工具链版本锁定（node/uv）
├── pitchfork.toml         # 守护进程编排（vcp-main + vcp-admin）
├── start-all-mise.sh      # 一键启动脚本（mise + pitchfork）
├── VCPToolBox/            # 后端（本仓库主项目）
│   ├── server.js          # 主服务（端口 PORT，默认 6005）
│   ├── adminServer.js     # 管理面板（端口 PORT+1 = 6006）
│   ├── config.env         # 核心配置（密钥、模型、开关）
│   ├── config.env.example # 配置模板
│   ├── multimodal-config.json  # 多模态识别配置（JSON 真相源）
│   ├── agent_map.json     # Agent 名称 → 角色卡文件 映射
│   ├── Agent/             # Agent 角色卡目录（.txt 设定 + 头像）
│   ├── TVStxt/            # 系统提示词变量文件
│   ├── Plugin/            # 300+ 插件（同步/异步/静态/服务/混合）
│   ├── dailynote/         # 日记（热记忆库）
│   ├── knowledge/         # 冷知识库（TDBKnowledge 图数据库）
│   ├── AdminPanel-Vue/    # 管理面板前端源码（需构建）
│   └── scripts/           # 维护脚本（索引重建、语义分类器等）
└── VCPChat/               # 桌面客户端（Electron）
    ├── main.js            # Electron 主进程
    ├── AppData/           # 用户数据（settings.json、Agents、话题）
    ├── rust_chat_data_service/  # Rust 聊天数据服务（需编译）
    ├── rust_audio_engine/       # Rust 音频引擎（需编译）
    └── ScriptoriumModules/      # 共笔文坊（本地文档创作）
```

## 5. 端口清单

| 端口 | 用途 | 配置项 |
|---|---|---|
| 6005 | VCP 主服务 API / WebSocket | `PORT`（config.env） |
| 6006 | 管理面板 | 自动 = `PORT+1` |
| 63789 | Rust 音频引擎（VCPChat） | audio_engine/.env |
| 动态 | Rust 聊天数据服务 VCP-CDS | 自动分配 |
| 5974 | 分布式服务器（可选） | VCPChat/VCPDistributedServer/config.env |
