<h1><center>自用脚本 (MyScripts)</center></h1>

# 总体描述

`dotfiles/MyScripts/.local/bin/` 是个人环境自用脚本集合, 部署后进入 PATH 可直接执行.

脚本全部面向 Arch Linux + KDE Plasma Wayland 环境, 部分依赖 pacman 包, 依赖清单见各脚本头部注释.

两个通用设计贯穿所有脚本:

1. 中英双语输出, 根据 `LC_ALL`/`LC_MESSAGES`/`LANG` 自动选择语言
2. 使用 `LANG_TABLE` 文本表 + `while IFS='|' read` 解析为变量, 切换语言只影响显示, 不影响逻辑

分类总览:

| 分类 | 脚本 |
|---|---|
| 系统维护 | archupdate, archclean, quicksnap |
| 文件与系统 | mount_win, varlogs, whatsmyip |
| 截图与贴图 | pinpic, pinpic-stitch, text_to_img |
| 多媒体 | kew_playlist, mpv_visual_audio |
| 系统集成 | user_dbus |

# 系统维护

## archupdate

Arch Linux 系统更新助手, 一条命令完成"看新闻 -> 确认 -> 更新"的安全更新流程.

**机制**:

- 参数解析采用 GNU 风格: `--ui-lang zh|en`, `--news-source official|cn`, `--count N`
- 先 `sudo -v` 请求权限, 再启动后台子进程每 60 秒执行 `sudo -n true` 保持 sudo 有效, 退出时通过 trap 杀掉保活进程
- 用 `command -v` 依次探测 paru, yay, 决定更新命令; paru 额外加 `--skipreview` 免去逐包确认
- 更新前拉取 RSS 新闻(官方源或 archlinuxcn 源), 由脚本内置的 Python 代码解析: 清洗控制字符防终端转义注入, 标题含 "intervention/manual/手动/干预" 的条目标红, 并用 OSC 8 转义生成终端可点击链接
- 新闻获取成功后询问确认, 失败则反问是否强制更新, 两种路径最终都进入 5 步更新:
  1. `pacman -Sy` 单独更新 keyring, 检测到 `[archlinuxcn]` 源时自动附带 `archlinuxcn-keyring`
  2. `paru -Syu` (或 yay) 升级系统, 失败即报错退出并提示"成功前勿装新包"
  3. 检测到 flatpak 时执行 `flatpak update -y`
  4. 检测到 `grub-mkconfig` 时重新生成 `/boot/grub/grub.cfg`
  5. 检测到 mise 时执行 `mise self-update` 和 `mise upgrade`

## archclean

系统清理助手, 默认列出清理清单并确认, 可用 `-y` 跳过确认, `--all` 进入激进模式.

**机制**:

- 包管理器探测优先级: paru > yay > pacman, 孤儿包和缓存操作走探测到的命令
- 孤儿包: 用 `pacman -Qtdq` 列出无依赖引用的包, 非空则 `$HELPER -Rns --noconfirm` 连带配置一并删除
- 缓存: 默认 `pacman -Sc`(保留当前版本可降级), `--all` 时 `-Scc` 清空, 并额外删除 `~/.cache/yay/*` 和 `~/.cache/paru/clone/*` 的 AUR 构建克隆
- 残留下载目录: 在 `/var/cache/pacman/pkg` 下按 `download-*` 模式删除中断下载的临时目录
- 日志: `journalctl --vacuum-time=2weeks` 只保留最近两周
- 回收站与缩略图: 回收站全部清空; 缩略图只删 `atime` 超过 30 天的文件, 保留常用缩略图加速
- Flatpak: `flatpak uninstall --unused -y` 移除未使用的运行时

## quicksnap

snapper 快速快照, 用法: `quicksnap [TAG]`, TAG 作为描述后缀.

**机制**:

- 先对 root 和 home 两个配置各执行一次 `snapper cleanup number`, 按数量算法清理过期快照
- 再分别 `snapper create --description qs-root[-TAG] --cleanup-algorithm number` 创建新快照, 挂上清理算法便于后续自动回收
- 完成后 `notify-send` 弹通知, 适合在更新前手动执行(如 `quicksnap before-update`)

# 文件与系统

## mount_win

按需挂载 Windows NTFS 分区, 默认只读, 防止 Fast Startup 休眠状态挂载导致数据损坏.

**机制**:

- 分区配置在脚本顶部数组, 格式 `设备|挂载点`, 不写进 `/etc/fstab`
- 状态检测用 `findmnt --source <设备> --target <挂载点>` 区分三态: 按配置挂载 / 挂到别处 / 未挂载, 并用 `findmnt -o OPTIONS` 判断当前 ro/rw
- 先输出状态表, 再自动决策: 有挂到别处的分区直接警告退出并给出卸载建议; 全未挂载 -> 挂载; 全已挂载 -> 卸载; 混合状态 -> 交互选择
- 挂载用内核 ntfs3 驱动, 参数 `uid=1000,gid=1000,umask=022`; 只读模式加 `ro`, 读写模式需显式选择并附加 `force` 绕过 ntfs3 对 dirty/hibernated 状态的保护限制

## varlogs

同时跟踪 `/var/log` 下所有文本日志.

**机制**:

- `find /var/log -type f -exec file` 识别文件类型, 过滤出 text 类型, 再用 `grep -v '[0-9]$'` 排除带数字后缀的轮转日志
- 结果交给 `xargs tail -f` 实时跟踪

## whatsmyip

显示内网和外网 IP.

**机制**:

- 主 IP: `ip route get 1.1.1.1` 触发内核路由查询, 用 awk 从输出提取 `src`(源地址)和 `dev`(出站网卡)
- LAN IP: 遍历 `ip -o -4 addr show up`, 排除 lo, tun, tap, docker, veth 等虚拟接口
- 外网 IP: `curl -4 --max-time 3 ifconfig.me`, 超时或失败显示 N/A

# 截图与贴图

## pinpic

Wayland 下的 Snipaste 替代品, 截图或剪贴板内容以置顶贴图显示, 三种模式:

```bash
pinpic --screenshot # 区域截图后贴图, 对应 Snipaste F1
pinpic --clipboard  # 剪贴板内容贴图, 对应 Snipaste F3
pinpic --stitch     # 多次截图拼接成长图后贴图
```

**机制**:

- 用 `mktemp -d` 建临时目录, trap EXIT 统一清理
- 截图模式调用 `spectacle -b -n -r -o` 做无边框区域截图
- 剪贴板模式用 `wl-paste --list-types` 读剪贴板类型, 按优先级分发:
  1. 图片: 优先取 `image/png`, 失败兜底其他 image 类型
  2. 文件 (`text/uri-list`): 逐个解析 `file://` URI, 用 `tr -d '\r'` 去回车, `sed` 把 `%XX` 转成 `\xXX`, `printf '%b'` 做 URI 解码; 图片文件直接贴图, 视频文件直接交给 mpv 播放
  3. 富文本 (`text/html`): 写入临时 html 后交给 text_to_img 渲染成图
  4. 纯文本: 优先选带 charset 的类型, 去回车后检测 GIF 链接(正则匹配 `http(s)://...gif`), 命中则 `curl` 下载原始文件保持动画(剪贴板复制 GIF 往往只有单帧); 其余文本交给 text_to_img
- 贴图显示走 mpv: `--script=~/.config/mpv/lua/pin_image.lua --no-config --no-input-builtin-bindings`, Lua 脚本负责置顶和无边框交互
- 拼接模式调用 `pinpic-stitch --out 临时文件`, 输出非空才贴图

## pinpic-stitch

多次截图自动拼接成长图, 提供浮动控制面板, 是 pinpic --stitch 的后端.

**机制**:

- PySide6 无边框置顶窗口, 三个按钮: 关闭, 截图, 完成; 中部实时显示帧数和累计高度
- 点截图后按钮置灰, 后台线程执行 `spectacle -b -n -r -o 临时文件`, 成功则用 PIL 读入 `ImageStitcher`(记录最大宽度), 通过 Qt 信号回到 UI 线程恢复按钮
- 点完成时垂直拼接: 画布宽度取最大宽度, 高度为各图之和; 较窄的图先 `_detect_bg` 取右边缘像素做 16 级颜色量化, 统计众数作为背景色, 向右补色条
- 保存 PNG 到 `--out` 后退出, 由 pinpic 调 mpv 贴图

## text_to_img

把文本或 HTML 渲染成 PNG, 供 pinpic 和独立命令行使用.

**机制**:

- 基于 Qt WebEngine(`QWebEngineView`)无头渲染, `WA_DontShowOnScreen` 隐藏窗口
- 输入套入深色主题 HTML 模板: 文本走 `pre` + monospace 字体, 限制最大宽度并 `pre-wrap` 换行; HTML 模板内用脚本给所有元素追加 Nerd Font 兜底字体, 避免图标字形缺失
- 文本输入先做 `\uXXXX` Unicode 转义解码, 兼容复制自终端等含转义的内容
- 渲染流程: `setHtml` -> `loadFinished` -> 100ms 后 `runJavaScript` 取 `body.scrollWidth/scrollHeight` -> 按尺寸 resize -> 50ms 后 `view.grab()` 抓取像素保存
- `setZoomFactor(1 / devicePixelRatioF() * 1.25)` 处理高分屏缩放
- 支持文件或 stdin(`-`)输入, `--text` 与 `--html` 互斥

# 多媒体

## kew_playlist

kew 播放器 wrapper, 解决 kew 官方不支持临时多文件播放的缺口.

**机制**:

- 单文件: `exec kew play` 直接替换当前进程, 无额外开销
- 多文件: 用 `uuidgen` 生成唯一播放列表名, 各文件 `realpath` 后写入 `~/Music` 下的临时 `.m3u`, 再 `kew list` 加载; trap EXIT 删除临时列表
- 配合 yazi 批量选择文件使用, 等 kew 官方支持后可直接删除本脚本

## mpv_visual_audio

终端内音频频谱可视化播放, MPV + Kitty 图形协议, 仅供娱乐.

**机制**:

- `--vo=kitty` 用 kitty 图形协议把画面渲染进终端, `--vo-kitty-use-shm=yes` 走共享内存提升性能
- `--lavfi-complex` 构建 FFmpeg 滤镜图: `asplit` 把音频分两路, 一路 `showfreqs` 生成频谱条(1280x720, `fscale=log` 对数刻度贴合人耳感知, `ascale=sqrt` 压缩动态范围防高频过亮, `win_size=4096` + blackman 窗口提高平滑度), 另一路 `anull` 原样输出音频
- 频谱配色为三段渐变色, 脚本内预置 Deep Forest / Deep Purple / Steel Blue / Teal 四套, 改 `COLORS` 变量即可切换

# 系统集成

## user_dbus

私人 D-Bus 服务, 在用户总线暴露可编程接口, 供其他程序或脚本调用.

**机制**:

- 基于 python-dbus-next 异步库, `MessageBus().connect()` 连上用户会话总线
- 通过 `bus.export()` 把接口对象挂到路径 `/org/user/services/ydotool`, 再 `request_name()` 注册服务名 `org.user.services`, 进程常驻事件循环
- 接口 `org.user.services.ydotool` 提供两个方法: `Key(sequence)` 用 `shlex.split` 安全拆分后执行 `ydotool key`, `Type(text)` 执行 `ydotool type`
- 调用示例:

```bash
busctl --user call org.user.services /org/user/services/ydotool org.user.services.ydotool Key s "ctrl+alt+t"
```
